## 给想法留一个地方

一直想有一个属于自己的博客。不需要复杂的功能，能打开、能阅读、能持续写下去，就已经很好。

这是这里的第一篇文章，也是一份小小的开场白。以后我会记录开发中的实践、读到的好内容，以及日常生活里冒出来的问题。

## 从简单开始

这个博客使用 **TanStack Start 和 React**。文章保存在仓库里的 Markdown 文件中，和代码一起管理；每次修改，都有清晰的记录。

本地启动只需要：

```bash
npm ci
npm run dev
```

打开首页，可以看到按日期排列的文章；点击标题，就能进入独立的详情页。文字是主角，其他东西尽量保持简单。

## 接下来想写什么

- 做项目时遇到的问题，以及最后如何解决。
- 学习一项技术时，真正帮助理解它的例子。
- 从阅读和生活里留下的一点思考。

> 不必等一切准备完美，先把第一篇写出来。

如果你也想开始记录，可以从今天解决的一个小问题写起。关于记录这件事，我还写了[把写作当成思考的一部分](/posts/writing-as-thinking)。
